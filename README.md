# DEM Multi Service — Prototype de site

Maquette interactive et personnalisée du site web de **DEM Multi Service (DMS)**, entreprise de graphisme.

## Objectif

Ce prototype sert à présenter au client une proposition visuelle concrète de son futur site : identité graphique, mise en page, typographie et animations au défilement. C'est une maquette de démonstration, pas un site de production.

## Contenu

- **En-tête** : logo DMS, navigation (menu burger sur mobile)
- **Accueil** : section d'ouverture animée au défilement
- **Nos Réalisations** : présentation des travaux de l'entreprise

## Identité visuelle

- Couleurs : bleu `#082D85`, orange `#FF5C03`
- Polices : Urbanist (titres), Archivo (texte), Allura (accents manuscrits)
- Mise en page responsive (desktop et mobile)

## Fichiers

- `DMS Accueil.html` — version autonome, à ouvrir directement dans un navigateur
- `DMS Accueil.dc.html` — fichier source de la maquette
- `assets/` — logo et images

## Lancer le prototype

Ouvrir `DMS Accueil.html` dans un navigateur récent. Aucune installation requise.
